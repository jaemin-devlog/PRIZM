Kiosk client 운영 기록

Active kiosk client
The active kiosk client uses KioskLink 8.4 for signed device messages in production.

Retired kiosk client
폐기된 kiosk client는 KioskLink 8.1을 사용했고 현재 배포 대상에서 제외됐다.

Current maintenance window
승인된 maintenance window 시작일은 2026-09-10이며 현장 장비 점검이 함께 진행됐다.

Earlier maintenance window
이전 승인 주기의 maintenance window 시작일은 2025-12-15였고 당일 복구 훈련을 마쳤다.
