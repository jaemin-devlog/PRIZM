# 개발 기록

날짜별 전체 기록과 기존 section heading은
[전체 개발 기록](archive/development-log-full-history.md)에 보존합니다. 이 파일은 기존
파일 경로의 안내 진입점으로 유지합니다. 과거 heading fragment를 사용한 외부 deep
link는 archive의 새 경로를 사용해야 합니다.

현재 제품을 이해하려면 다음 문서를 먼저 확인하세요.

- [현재 구현 현황](project-status.md)
- [PRIZM 제품 범위](roadmap.md)
- [Spec Registry 도입 전 구현 이력](../specs/000-pre-spec-implementation-history.md)
- [Spec Registry](../specs/README.md)

과거 기록의 날짜, 환경과 판정은 현재 상태에 맞춰 소급 변경하지 않습니다.
