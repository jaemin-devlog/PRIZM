# PRZ-018 — 문서 상세 미리보기 페이지

> **상태:** `VERIFIED`
> **유형:** Feature
> **기준 소스:** `d3b0096385366d0c3f617dd688d5b22d77f20c6f`
> **작성일:** 2026-08-27

## 목적

문서 카드의 `상세 보기`를 모달이 아닌 별도 화면 흐름으로 전환한다. 사용자는
선택한 버전의 첫 페이지 미리보기를 크게 확인하고, 오른쪽 버전 목록에서 다른
버전을 선택하거나 새 버전을 등록할 수 있어야 한다.

## 범위

### 포함

- 기존 `documentId` URL을 사용하는 문서 상세 페이지
- PDF 첫 페이지 미리보기와 TXT 대체 화면
- 오른쪽 버전 목록과 선택한 버전 표시
- 선택한 PDF 원문 열기
- 기존 문서 정보·태그·버전·삭제 관리 기능 유지
- 브라우저 뒤로가기와 목록 복귀
- 데스크톱과 모바일 반응형 배치

### 제외

- backend API, 인증, ownership와 `ACTIVE` 전환 계약 변경
- PDF 전체 페이지를 애플리케이션 내부에서 직접 렌더링하는 기능
- TXT 원문 편집, 새 문서 형식과 새 dependency
- 검색, Job Posting Evidence와 MCP 동작 변경

## 보존 계약

- 모든 문서·버전·thumbnail·원본 요청은 기존 JWT와 owner-scoped API를 사용한다.
- 미완성 버전은 검색 후보가 되지 않으며 기존 `ACTIVE` 버전을 유지한다.
- 새 버전 등록, 이전 버전 삭제와 문서 삭제의 기존 제한을 유지한다.
- PDF 원문은 기존 인증 요청과 object URL 기반 viewer를 사용한다.

## 요구사항 및 완료 조건

### `PRZ-018-R1` — 페이지 전환

`상세 보기`가 `documentId`가 포함된 URL로 이동하고, 모달 backdrop 없이 문서 상세
페이지를 표시한다. `목록으로`와 브라우저 뒤로가기로 목록에 복귀할 수 있다.

### `PRZ-018-R2` — 버전별 미리보기

선택한 버전의 파일명, 버전 번호, 상태와 PDF 첫 페이지 thumbnail을 표시한다. TXT나
thumbnail을 표시할 수 없는 경우 파일 형식을 알 수 있는 대체 화면을 제공한다.
미리보기는 문서 관리 영역을 과도하게 밀어내지 않는 크기로 표시한다.

### `PRZ-018-R3` — 버전 탐색과 관리

오른쪽 목록에서 버전을 선택하면 주 미리보기가 바뀐다. 새 버전 등록, 이전 버전
삭제, 처리 진행·실패 정보와 `ACTIVE` 표시를 기존 계약대로 유지한다.

### `PRZ-018-R4` — 문서 관리 기능

제목·유형 수정과 태그 관리는 하나의 전체 너비 카드에서 위아래로 이어진다. 문서
삭제와 PDF 원문 열기도 새 페이지에서 동작한다.

### `PRZ-018-R5` — 반응형·접근성

좁은 화면에서는 미리보기와 버전 영역이 한 열로 배치된다. 버전 선택 상태와 loading,
오류, dialog의 접근성 속성이 유지된다.

### `PRZ-018-R6` — 회귀 방지

frontend unit test, lint와 production build가 통과하며 backend·SQL·migration·dependency는
변경하지 않는다.
